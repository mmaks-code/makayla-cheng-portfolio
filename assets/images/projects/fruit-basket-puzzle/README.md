# 3D Fruit Basket Puzzle images

Add your photos to this folder using the filenames below. The project card and project page already point at these paths, so you do not need to edit any HTML.

- `cover.jpg` — Photograph of the finished fruit basket puzzle. This is already in use as the project card image and the cover. `cover.HEIC` is the original photo.
- `Technical Fruit Basket Puzzle CAD Layout.png` — Rhino CAD drawing of the assembled puzzle. This is already in the project gallery.
- `fabrication.jpg` — Optional photo of the laser-cut or 3D-printed components. This appears in the project gallery when the file is here.

Until a file is added, that image is left off the page. If `cover.jpg` is missing, the card and project page show a plain “Cover image coming soon” box instead of a broken image.
